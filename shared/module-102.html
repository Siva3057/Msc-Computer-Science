Secure Software Development

A core MSc module covering secure software development, assessed through a group coursework project and an individual written report.

Learning outcomes

as set by the module
  1. An understanding of the basic principles of secure and sustainable development methodologies.
  2. An understanding of the basic principles of architecture, as well as traditional and contemporary Software Development Life Cycle (SDLC) models, such as TOGAF and Agile.
  3. An ability to undertake analysis of a real-life problem domain, program design, software construction, and testing required for software development, supporting entrepreneurial coding ideas.
  4. Opportunities for exploring software design using the Unified Modelling Language (UML).
  5. Experience with code documentation to support maintainable code production.
  6. A critical understanding of the concept of abstraction in programming.
  7. The ability to put into practice the techniques learned in a team environment, demonstrating how to make compromises, support the equality and diversity of opinion, and be able to critically evaluate the effectiveness of others’ approaches.
